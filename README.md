A standalone, GitHub-compatible git forge: one Node 22 process serving git smart HTTP, the REST v3 API, GraphQL v4 and MCP from its own in-memory store, with no UI, no git binary and no dependency outside the standard library.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 node --experimental-strip-types main.ts
```
